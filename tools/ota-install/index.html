🔄 AltStore 安装流程

1
在 PC（Windows/Mac）上下载安装 AltServer
从 altstore.io 下载，需要 iTunes 或 Apple Devices
2
iPhone 用数据线连接 PC，AltServer 托盘图标 →
Install AltStore → 选择你的 iPhone → 输入 Apple ID
3
iPhone 上：设置 → 通用 → VPN与设备管理 → 信任开发者
4
在 iPhone Safari 打开下方链接，点击「安装 AltStore IPA」
5
保持 AltServer 在 PC 后台运行，手机和 PC 在同一局域网
→ 每7天自动续签，完全无感知
📲 安装 HandyCode（AltStore OTA） ⬇️ 下载 IPA 文件（手动导入 AltStore）
OTA 安装必须在 Safari 中打开本页面。微信/Chrome 内置浏览器不支持。

🖥️ Sideloadly 安装流程

1
在 PC 上下载 Sideloadly：sideloadly.io
2
下载 IPA 文件到电脑（见下方按钮）
3
iPhone 用数据线连接电脑，打开 Sideloadly →
将 IPA 拖入 Sideloadly → 填写 Apple ID → 点 Start
4
iPhone：设置 → 通用 → VPN与设备管理 → 信任
5
7天后需重新用 Sideloadly 安装一次（或配合 AltServer 自动续签）
⬇️ 下载 IPA 文件（用于 Sideloadly）
