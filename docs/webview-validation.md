# WebView 验证说明

构建脚本执行 URL 白名单、登录门禁、DOM 投影、分区刷新、切换、退出隔离和京东订单识别回归，并校验 DEX、APK 对齐、签名及包版本。

身份码亮度回归覆盖未加载图片、隐藏内容、屏幕外内容和可见身份条码。只检查展示节点与可见性，不读取码值或凭据。

发布前应在设备上验证：

1. 官方登录、身份码显示、刷新及过期更新。
2. 底栏点击、拖动、快速连续切换时标题清晰且页面状态保留。
3. 身份码出现时提亮，滚出可视范围、切页、弹窗、后台及锁屏后恢复原窗口亮度。
4. 淘宝、拼多多与京东独立退出，再次登录及重启后的会话行为。
5. 有实际待取包裹时核对取件码，并在驿站验证扫码。

自动化检查不代替真实账号、平台风控和扫描设备的端到端验收。上游 H5 结构变化可能影响展示与识别。

## 0.8.1（2026-11-14）

- 正式构建通过 7 组 Java 回归与 20 项 JavaScript/DOM 回归；APK 为 0.8.1 / versionCode 35，关闭应用及 WebView 调试，通过 v2/v3 签名校验并沿用既有证书。
- 正式 APK 已覆盖安装并冷启动；没有为验证清除真实账号数据。升级后仍需登录的场景不等同于所有官方会话都能永久保留。
- 本轮开发中核对了四个平台首次加载身份码高度、淘宝空包裹居中、菜鸟刷新尺寸与京东刷新文字位置；京东官方身份码曾在真机展示、刷新和旋转放大。
- 淘宝昼夜交接检查采集 534 个窗口画面样本，覆盖点击、两个方向的拖动及拖回取消。正常单向切换未测到颜色反向跳变；取消手势按预期返回原配色。窗口采样不代表所有设备、WebView 或网络条件均已覆盖。
- 淘宝登录页在真机检查了手机号阶段的配色、区号和显示交接；验证码阶段完成结构与配色测试，此次没有实际发送短信。
- 拼多多官方登录页已在独立测试环境检查下方提示位置及进入手机登录表单后的布局，没有重用或清除用户账号来做该项测试。
- 没有待取的京东商城订单，真实订单取件码、驿站扫码和完整到期更新周期仍待实际场景验证。
- 真机截图、录屏、日志及研究中间文件不进入版本控制与 Release 附件；发布附件仅为 APK 及 SHA256 校验文件。
