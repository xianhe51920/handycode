# WebView 验证说明

构建脚本执行 URL 白名单、登录门禁、DOM 投影、分区刷新、切换、退出隔离和京东订单识别回归，并校验 DEX、APK 对齐、签名及包版本。

身份码亮度回归覆盖未加载图片、隐藏内容、屏幕外内容和可见身份条码。只检查展示节点与可见性，不读取码值或凭据。

发布前应在设备上验证：

1. 官方登录、身份码显示、刷新及过期更新。
2. 底栏点击、拖动、快速连续切换时标题清晰且页面状态保留。
3. 身份码出现时提亮，滚出可视范围、切页、弹窗、后台及锁屏后恢复原窗口亮度。
4. 淘宝、拼多多与京东独立退出，再次登录及重启后的会话行为。
5. 有实际待取包裹时核对取件码，并在驿站验证扫码。

自动化检查不代替真实账号、平台风控和扫描设备的端到端验收。上游 H5 结构变化可能影响展示与识别。
