## 0.5.3：自动衔接及刷新恢复

用户确认可登录，反馈登录后需多次刷新才能显示。修复代码中明确存在的连续 mutation 使 debounce 一直推迟、缓存 iframe 可能错过 load 事件、未完成条形码就标记 ready，以及顶部刷新总重建整个文档等问题。

原生层监听登录过程及页面历史变化，弹窗显示真实身份码后自动返回父页面。顶部刷新优先调用局部刷新接口，未合并时对重复点击节流。未登录时仍保留完整官方页面。
