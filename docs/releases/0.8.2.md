# HandyCode 0.8.2

发布日期：2026-11-15。版本代码：36。支持 Android 8.0 及以上。

本次为登录兼容性修复，保留菜鸟、淘宝、拼多多、京东四个页面及已有功能。

## 修复

1. **京东点击「同意协议并登录」无反应**：官方登录按钮使用链接元素，旧规则因按钮文字含「协议」而误拦截点击。本版放行登录、同意并继续等操作，保留官方提交与验证流程；协议正文链接仍不跳转，确认圈继续由用户勾选。
2. **淘宝登录框可能一直被加载层遮住**：部分官方登录表单先隐藏，再只通过 class、style 等属性显示。新增这类变化的就绪检查，避免遗漏已经出现的登录表单。
3. **淘宝加载超时可能失效**：检测到登录 iframe 时不再提前停止计时，统一等待登录表单主题绘制完成后再结束加载。普通网页回调不再使独立超时检查失效；超时提供重新打开入口，并区分登录页与取件信息未就绪。
4. **调整淘宝超时说明**：通用加载失败不再直接要求先在淘宝 App 开通身份码，避免把网络或网页未就绪误判为未开通。

## 更新安装

下载 `HandyCode-0.8.2-release.apk`，直接覆盖安装即可。包名与签名证书沿用旧版，更新不主动清除应用数据或网页登录状态，无需卸载。

平台会话过期、风控或此前主动退出时，仍需在官方网页重新登录。

## 验证与边界

- 通过 7 组 Java 回归、20 项 JavaScript/DOM 回归，新增京东链接式登录按钮、嵌套点击及淘宝表单仅通过样式变化显示的回归场景。
- 正式 APK 检查版本、包名、关闭调试状态、对齐与 v2/v3 签名，并核对沿用既有签名证书。
- 京东按钮误拦截与淘宝样式就绪检测问题已在回归场景复现并修正；京东短信登录已实测通过。
- 官方网页、WebView 版本、网络及平台风控仍可能影响登录。本版不保证解决所有登录失败，也不改变拼多多网页与官方 App 可能互相挤下线的限制。
