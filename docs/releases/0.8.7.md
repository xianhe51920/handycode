# HandyCode 0.8.7

发布日期：2026-11-22。版本代码：41。支持 Android 8.0 及以上。

本次更新修复拼多多前端构建升级后「身份码」与「待取包裹」无法分段刷新的问题，并降低后续平台脚本分包调整带来的脆弱性。

## 更新内容

1. **修复拼多多分段刷新失效（适配 2026-11-22 前端新构建）**：
   - `UrlPolicy` 新增 `isPddNumericChunk`，不再把分段刷新拦截限定在旧的固定 chunk ID（`1235` / `8905` / `5709`），统一由 `PddPage` 尝试适配数字 chunk，已适配脚本按 `no-store` 下发并写入 `pdd_bundles_v3` 缓存，未命中适配的其余数字 chunk 仍按不可变资源缓存。
   - `PddBundleAdapter` 改用结构与唯一锚点正则匹配（不依赖混淆单字母变量名），兼容新版身份码组件（`8173`）与新版 Redux 包裹列表组件（`5685` 的 `refreshPackagePage` / `queryStationPackageInfo`），同时继续保持严格 fail-closed 校验。
2. **动态识别定位与 HTTP 客户端模块**：
   - `pdd-same-origin.js` 改为按模块导出与特征动态识别定位模块（`J7` / `By`）与 HTTP 模块（`BACKEND_API` / `isApiRequest`），避免 `_app` 模块 ID 变动（`41027` → `82469`、`83101` → `96133`）导致同源定位与加包流程失效，并在 `pdd-section-refresh.js` 中补充运行时兜底注册机制（`registerFallback`）。

## 更新安装

下载 `HandyCode-0.8.7-release.apk`，直接覆盖安装即可。包名与签名证书沿用旧版，更新不主动清除网页登录状态，无需卸载。

## 验证与边界

- 通过全部 Java 回归（7 个测试类）与 JavaScript / DOM 回归（20 个 `.test.mjs` 测试套件），并使用真实线上 `8173` / `5685` chunk 验证 `PddBundleAdapterTest` 适配与 JS 语法检查通过。
- 正式 APK 已完成包名、关闭调试标志、4 字节对齐与 v2/v3 签名及已有签名证书核验。
- 已在无线调试真机（Android 16）通过覆盖安装实测拼多多「身份码」与「待取包裹」分段刷新恢复正常。
