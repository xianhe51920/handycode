# HandyCode 0.8.3

发布日期：2026-11-19。版本代码：37。支持 Android 8.0 及以上。

本次主要修复京东已到站商城包裹未显示的问题，并统一卡片排版与京东 App 一键跳转体验。

## 更新内容

1. **修复京东已到站包裹被漏掉的问题**：
   - 在加载京东订单页前通过 `DOCUMENT_START_SCRIPT` 提前注入采集脚本，避免首屏请求早于注入时机。
   - 新增订单 `promptInfo`（`content` + `variableList` 占位符）解析，并扩展取件码、开箱码、取件密码及驿站货架号格式识别。
   - 当订单已派送至驿站/自提点（例如订单状态仍为「等待收货」且摘要提示凭取件码领取、但网页端未下发具体数字取件码）时，不再过滤成「暂无待取包裹」。
2. **京东包裹卡片排版与商品缩略图**：
   - 对齐拼多多卡片的视觉排版（复用同款 `16×16` 驿站矢量图标、左侧细竖线、商品缩略图、简洁标题与副文案）。
   - 商品缩略图仅从 `https://*.360buyimg.com` 与 `https://*.jd.com` 加载。
3. **一键跳转京东 App 原生待取件页**：
   - 点击包裹卡片或「在京东 App 查看物流 ›」，可通过 `openapp.jdmobile://virtual`（`des: "orderTrack"` + `orderId`）直接拉起京东 App 的原生待取件/物流详情页查看取件码。
4. **修正接口繁忙提示**：
   - 京东订单页触发「大促异常火爆 / 服务繁忙」限流时，不再误显示为「暂无待取包裹」，改为明确提示「取件信息暂未更新 / 京东订单页面当前繁忙，请稍后点刷新重试」。

## 更新安装

下载 `HandyCode-0.8.3-release.apk`，直接覆盖安装即可。包名与签名证书沿用旧版，更新不主动清除应用数据或网页登录状态，无需卸载。

## 验证与边界

- 通过 7 组 Java 回归、20 项 JavaScript/DOM 回归，新增 `promptInfo` 占位符、开箱码、无短码到站包裹、缩略图与链接域校验回归场景。
- 正式 APK 检查版本、包名、关闭调试状态、对齐与 v2/v3 签名，并核对沿用既有签名证书。
- 已在真机（`PKW110`）实测通过已到站京东商城包裹显示、拼多多同款排版、商品缩略图、跳转京东 App 原生待取件页及接口繁忙状态提示。
