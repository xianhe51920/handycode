# HandyCode 0.8.4

发布日期：2026-11-19。版本代码：38。支持 Android 8.0 及以上。

本次为显示兼容性修复，解决系统关怀/大字模式下页面文字放大导致的排版错位问题（Fixes #10）。

## 修复

1. **锁定业务 WebView 文字缩放为 100%**：
   - 在菜鸟、淘宝、拼多多、京东订单与京东身份码页面统一设置 `WebSettings.setTextZoom(100)`，避免系统 `font_scale` 放大 WebView 内固定高度与行高投影容器中的文字，导致包裹列表重叠错位。
2. **统一京东原生卡片字体单位**：
   - 将 `JdPage` 与 `JdIdentityCard` 内的卡片标题、按钮、空状态提示及包裹卡片文字统一改为 `COMPLEX_UNIT_DIP`（`dp`），确保在关怀/大字模式下与其余三个平台保持一致的视觉比例。

## 更新安装

下载 `HandyCode-0.8.4-release.apk`，直接覆盖安装即可。包名与签名证书沿用旧版，更新不主动清除应用数据或网页登录状态，无需卸载。

## 验证与边界

- 通过 7 组 Java 回归与 20 项 JavaScript/DOM 回归。
- 正式 APK 检查版本、包名、关闭调试状态、对齐与 v2/v3 签名，并核对沿用既有签名证书。
- 已在真机（`PKW110`，系统 `font_scale = 1.5`）实测通过淘宝、拼多多真实包裹卡片与京东页的关怀模式排版。
