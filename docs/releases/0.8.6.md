# HandyCode 0.8.6

发布日期：2026-11-21。版本代码：40。支持 Android 8.0 及以上。

本次更新围绕**四平台加载与切页速度提升**以及**拼多多「添加包裹」功能修复与空状态排版优化**。

## 更新内容

### 一、加载与切页性能优化

1. **拼多多不可变静态资源持久化缓存与首帧投影提速**：
   - 在 `UrlPolicy` 与 `PddPage` 中新增对 `pfile.pddpic.com` 不可变哈希 `.js` / `.css` chunk 的识别与磁盘/内存两级缓存（`pdd_bundles_v2` 清理阈值由 `12` 扩至 `64`，内存缓存池扩至 `32` 项），冷启动无需重复回源或 304 协商，减少二次打开时的网络等待。
   - 优化 `WebAssets` 在应用启动时后台预加载本地注入脚本与模板；将 `pdd-layout.js` 无交互场景的投影防抖下限由 `160ms` 降至 `25ms`，并减少投影克隆与待取列表筛选时的冗余属性操作。
2. **淘宝已登录状态消除双重加载**：
   - 当检测到淘系会话处于已登录状态时，在 `MainActivity.shouldInterceptRequest` 阶段直接对主文档下发合卡页面模板，让身份码与待取包裹双 `<iframe>` 并发拉取数据，省去此前先完整加载一次官方身份码页面、待出码后再通过 `document.write` 覆写重载的一整轮请求与渲染耗时。
   - 若子框架发生鉴权跳转或上报登录态失效，自动无缝回退至顶层官方登录流程。
3. **前台就绪后后台错峰预热其余标签页**：
   - 前台当前平台完成首帧呈现（或达到 `2000ms` 兜底延时）后，按 `450ms` 错峰依次在后台静默预热其余已登录标签页（淘宝、拼多多、菜鸟、京东），未登录淘系时不静默拉起淘宝/菜鸟登录页；预热期间不运行离屏动画，就绪后自动暂停 WebView 与轮询，切页即可直接展示内容。

### 二、拼多多「添加包裹」修复与界面微调

1. **修复拼多多无法正常添加/查询包裹的问题**：
   - 修复待取包裹栏点击「添加包裹」无响应的路由问题，支持进入官方 `/mdkd/add-package` 查询表单。
   - 针对 WebView 环境缺少宿主定位导致接口返回「未能获取定位信息」「app距离校验降级」的问题，在 `pdd-same-origin.js` 与 `PddPage` 中通过站点详情接口与系统 `Geocoder` 解析站点坐标并向 `/api/ptolemeaus/location/report` 上报获取有效 `location_id`，恢复运单号查询与加包流程。
   - 补全查询结果弹窗、多单号选择弹窗、前缀查询弹窗及 `taobao-login`/内嵌表单深色主题样式适配。
2. **精简拼多多空状态排版**：
   - 隐藏待取包裹为空时卡片内部冗余的「您可尝试以下方式查询未展示快递」及底部「绑定手机号」「添加快递」按钮（顶部标题栏保留独立入口），并将空状态提示文案在卡片内居中显示。

## 更新安装

下载 `HandyCode-0.8.6-release.apk`，直接覆盖安装即可。包名与签名证书沿用旧版，更新不主动清除网页登录状态，无需卸载。

## 验证与边界

- 通过全部 Java 回归（7 个测试类）与 JavaScript / DOM 回归（20 个 `.test.mjs` 测试套件），涵盖拼多多不可变静态资源白名单、同源定位与加包补丁、空状态隐藏与居中投影、淘宝合卡监听与各页面布局规则。
- 正式 APK 已完成包名、关闭调试标志、4 字节对齐与 v2/v3 签名及已有签名证书核验。
- 已在真机（Android 14）通过直接覆盖安装完成拼多多加包流程、空状态居中显示及四标签页加载切换实测。
