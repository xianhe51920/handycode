# HandyCode 0.8.5

发布日期：2026-11-20。版本代码：39。支持 Android 8.0 及以上。

本次为覆盖安装与登录加载兼容性修复，解决应用覆盖安装（或保留旧 Cookie/缓存）后淘宝页面持续加载超时、需要清除全部应用数据才能正常使用的问题。

## 修复

1. **覆盖安装自动清理旧 WebView HTTP 缓存，重构试重置流程**：
   - 在 `MainActivity` 检测应用版本或 `PackageInfo.lastUpdateTime` 变化，覆盖安装后自动清理一次 WebView HTTP 磁盘缓存（保留已有网页登录态，不影响拼多多和京东），重置失效的淘宝需登录标记，并以 `WebSettings.LOAD_NO_CACHE` 发起一次无缓存刷新。
   - 点击「重新打开网页」重试时不再原地复用卡死的 `WebView`，而是销毁旧实例、清理 HTTP 缓存并重建干净 `WebView` 以无缓存模式重新加载。
2. **解除保留 Cookie 后记忆账号与风控验证页的主题等待死锁**：
   - 在 `UrlPolicy`、`TaobaoLoginTheme` 与 `taobao-login-theme.js` 中补入 `passport.taobao.com`、`login.tmall.com`、无输入框快捷确认登录按钮及 `aq.` / `sec.` / `punish` / `baxia` 验证场景识别，兼容 `about:blank` 控制台来源标识。
   - 在 `MainActivity` 为官方登录/验证页加入 `3500ms` 绘制宽限兜底揭罩，避免主题回调缺失时加载遮罩一直挡住页面直到超时。
3. **放宽淘宝入口匹配并提前触发状态探测**：
   - 淘宝身份码入口校验支持 `pages.m.taobao.com` 及末尾斜杠；在 `official-identity.js` 增加顶层认证/风控页检测，并在 `onPageCommitVisible` 阶段提前探测合卡与认证状态，避免第三方慢资源拖慢 `onPageFinished`。
4. **超时失败页新增仅重置淘宝入口**：
   - 在淘宝加载失败界面新增「清除淘宝缓存并重新登录」按钮，仅清除淘宝与菜鸟对应站点的 WebView 数据并重新加载，不影响拼多多和京东的登录状态。

## 更新安装

下载 `HandyCode-0.8.5-release.apk`，直接覆盖安装即可。包名与签名证书沿用旧版，更新不主动清除网页登录状态，无需卸载。
