# HandyCode 0.8.1

发布日期：2026-11-14。版本代码：35。支持 Android 8.0 及以上。

## 新增与完善

- **新增京东官方身份码**：身份码在上、商城订单取件码在下。复用官方网页登录会话，保留官方身份码生成、刷新与到期更新流程，支持点击旋转放大和扫码提亮。
- **统一四个平台的加载效果**：用圆点指示替代骨架灯条。身份码首次加载与加载完成使用相同的预留高度，包裹卡片按实际内容平滑调整，减少卡片突然挤动。
- **玻璃昼夜开关**：固定在标题栏右侧，支持点击、拖动预览和拖回取消，保留按钮光效。取消自动模式，记住手动选择的外观。
- **添加包裹与号码管理**：淘宝、拼多多在待取包裹标题旁提供运单号查询入口；官方号码管理、添加手机号及运单号查询页嵌入应用中间区域，适配深浅外观，隐藏图片上传与推广内容，必要的官方查询、验证和结果继续保留。
- **退出登录移到卡片下方**：仅退出当前平台。淘宝和菜鸟继续共用会话；未登录时不显示退出按钮。

## 修复

- 淘宝登录页及验证码阶段的深浅配色、区号文字重叠和次级登录按钮配色。
- 淘宝暗色启动时短暂白屏：加载层等待实际登录控件、主题样式及绘制就绪后再交接。
- 淘宝昼夜切换闪白：等待官方登录 iframe 确认主题，并通过 WebView 绘制屏障后再结束过渡；拖动松手及取消也走同一收尾流程。
- 拼多多多叠一层登录选择提示：现在直接显示官方登录页，小号使用建议放在登录内容下方。官方「打开拼多多 App」按钮仍可直达身份码。
- 登录页协议文字点击后跳离登录流程：拦截协议链接跳转，保留原确认圈、协议文字与官方勾选校验，不自动同意协议。
- 京东验证窗口的横滑手势与页面切换冲突，以及登录、验证页面的深浅配色。
- 京东刷新文字位置跳动、快速请求时状态一闪而过，及菜鸟刷新卡片高度变化。
- 淘宝空包裹提示未整体居中，以及身份码和包裹在刷新、切页时的部分布局与显示问题。

## 更新安装

下载 `HandyCode-0.8.1-release.apk`，直接覆盖安装。包名和签名证书沿用旧版；应用不会因覆盖更新主动清除网页登录数据。平台会话到期、风控或此前主动退出时，仍需重新登录。清除应用数据或卸载后重装也需要重新登录。

拼多多网页登录与官方 App 登录可能互相挤下线，这一平台限制仍存在。需要同时使用两端时，可按登录页提示用小号登录，再通过官方验证添加大号的收件手机号。

## 验证与边界

- 正式构建运行 Java 导航、刷新与退出队列回归，以及全部 JavaScript/DOM 回归；检查 APK 包名、版本、对齐、v2/v3 签名、关闭调试状态和签名证书一致性。
- 此轮真机已检查官方京东身份码显示、四个平台首次加载卡片高度、分区刷新布局，以及淘宝登录主题和昼夜切换。昼夜切换测试采集了 534 个窗口画面样本，覆盖点击、左右拖动及拖回取消；正常单向切换未测到颜色反向跳变。
- 淘宝验证码阶段完成结构与样式检查，此轮未实际发送短信；没有为测试清除真实账号登录状态。
- 测试账号没有待取的京东商城订单，真实订单取件码与驿站扫码仍需实际场景验证；也未完整等待所有平台的身份码过期周期。
- 官方页面、风控和网络变化仍可能影响加载与展示。当前页面不支持拍照、图片上传验证；遇到此类验证时需在官方客户端处理。
